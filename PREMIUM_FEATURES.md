# ExNihilo 95 — Technical Architecture & Unlocked Features Roadmap

> **Philosophy:** ExNihilo 95 is **100% Free and Open Source**. There are NO paywalls, NO locked features, NO subscriptions, and NO artificial limits. Every developer, student, educator, and team has full, unrestricted access to all capabilities at maximum potential.

## 🚀 Fully Unlocked Core & Advanced Architecture

| Capability | Details & Status |
|------------|------------------|
| **Zero-Config SQL Engine** | AST parsing, schema inference, referential integrity & synthetic data |

## 🗺️ Open-Source Innovation Roadmap

All roadmap pillars below are completely free and open for community collaboration:

### 🗂️ 1. Workspaces & Tab Management
- Unlimited tabs with drag-and-drop reordering.
- Color-coded tab grouping and persistent tab pinning.
- Named project workspaces (e.g. "E-Commerce", "Analytics Sandbox").

### 💾 2. Persistence & Sessions
- Local-first IndexedDB persistence with zero latency.
- Comprehensive session query timeline with execution latency and row metrics.
- Exportable session audit logs (.json) and formatted analytical reports (.txt).

### 🤖 3. AI-Powered SQL Intelligence (Copilot)
- Natural Language to SQL query generation.
- Plain-English query explanations for complex JOINs and CTEs.
- Context-aware AST error diagnostic hints and auto-fix suggestions.

### 📊 4. Data Visualization & Analytics
- In-IDE Chart Builder (bar charts, line graphs, pie charts, scatter plots).
- Dynamic SVG execution latency and memory trend monitors.
- Multi-query semicolon result tab splitting.

### 🎲 5. Domain-Contextual Synthetic Data Generation
- 3-tier domain dictionary with semantic matching (E-Commerce, Healthcare, Finance, HR, SaaS).
- Referential integrity enforcement with topological sorting.
- Configurable synthetic data limits (rows per table & max table cap in Settings).

### 🔗 6. Live Database Connectivity (Future Module)
- Optional direct connectors for external databases (MySQL, PostgreSQL, SQLite).
- Read-only safety guardrails for production exploration.

### 👥 7. Community & Collaboration
- Open-source issue tracking, discussions, and feature voting.
- Contributor recognition and co-creator credits.
- Shared query templates and community snippets library.
